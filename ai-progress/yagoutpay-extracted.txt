     This document describes the different methods of Integration between Merchant and

      their users using various payment modes like Credit cards, Debit cards & Wallets.

3. Encryption Decryption Logic.

     ALL the parameters are encrypted and decrypted using Aes 256 logic shared below
     with the help of merchant encryption key.

    function encrypt($text, $key, $type)
    {
    $iv = "0123456789abcdef";
    $size = 16;
    $pad = $size - (strlen($text) % $size);
    $padtext = $text . str_repeat(chr($pad), $pad);
    $crypt = openssl_encrypt($padtext, "AES-256-CBC",

                   base64_decode($key), OPENSSL_RAW_DATA
                   | OPENSSL_ZERO_PADDING, $iv);
    return base64_encode($crypt);
    }
    function decrypt($crypt, $key, $type)
    {
    $iv = "0123456789abcdef";
    $crypt = base64_decode($crypt);
    $padtext = openssl_decrypt($crypt, "AES-256-CBC",
                   base64_decode($key), OPENSSL_RAW_DATA
                   | OPENSSL_ZERO_PADDING, $iv);
    $pad = ord($padtext[strlen($padtext) - 1]);
    if ($pad > strlen($padtext)) {
    return false;
    }
    if (strspn($padtext, $padtext[strlen($padtext) - 1], strlen($padtext) -
    $pad) != $pad) {
     $text = "Error";
    }
    $text = substr($padtext, 0, -1 * $pad);
     return $text;
    }

4. Process Flow & Integration Methods.

    Yagoutpay supports collecting payment information using Aggregator Hosted method.
     This method is designed to support a smooth user-experience.

A. Aggregator Hosted (Non-Seamless):

     Avoid struggling to develop and manage your own checkout page.Use the customized
     payment page provided by yagoutpay which enables you to collect payment from the
     customer.

                         Aggregator Hosted (Non Seamless Flow)

Merchant                                           yagout                                             Bank

                                                        User Authentication user is redirected on
                                                        bank page for authentication

                                                           Bank sends transaction response to yagout

yagoutsends final transaction response to the merchant

Merchant                                           yagout                                             Bank

          Process flow:

          1. Customer selects product/service on your website and proceeds to make payment.
          2. Customer is redirected to the yagout payment page where payment information is
          entered by the customer.
          3. On submission of the transaction information, yagout initiates the authorization
          process by connecting to the relevant bank / processing organization.
          4. On receiving the authorization status from the bank, yagout sends the response back
          to your website with the transaction status.
